# Lesson 1: Photography Basics for Map Digitization

**Duration:** 60 minutes
**Difficulty:** Beginner
**Equipment Required:** Sony Alpha DSLR (or similar), tripod, color card

---

## Overview

Professional map digitization starts with high-quality photography. This lesson teaches you how to use a DSLR camera to photograph paper maps with the quality needed for georeferencing and archival preservation.

---

## Learning Objectives

By the end of this lesson, you will:

1. ✅ Set up a DSLR camera for document photography
2. ✅ Use a color card for accurate white balance
3. ✅ Configure camera settings for maximum quality
4. ✅ Position camera and lighting properly
5. ✅ Assess image quality
6. ✅ Transfer images to computer for processing

## Part 1: Equipment Setup (15 minutes)

### Essential Equipment

**Camera:**
- Sony Alpha DSLR (or similar DSLR/mirrorless)
- Charged battery
- Memory card with adequate space

**Support:**
- Tripod (essential!)
- Copy stand (ideal but not required)
- Overhead mount (alternative)

**Accessories:**
- Color card (X-Rite ColorChecker or similar)
- Remote shutter release or timer
- Lens cleaning cloth

**Lighting:**
- Natural indirect light (ideal)
- Two matching lamps (if artificial light needed)
- Diffusers to soften harsh light

**Map Preparation:**
- Flat, clean surface
- Weights to hold map flat (if needed)
- Clean the map gently if dusty

### Camera Positioning

**The Goal:** Camera sensor parallel to map surface

**Setup:**
1. Place map flat on table or floor
2. Position tripod directly above map
3. Camera pointing straight down
4. Use level if available (many cameras have built-in level)
5. Fill frame with map but capture all edges

**Why This Matters:**
- Parallel positioning prevents keystoning (distortion)
- Even distance across map ensures sharp focus
- Proper framing minimizes wasted pixels

### Lighting Setup

**Best Option: Indirect Natural Light**
- Position near window
- Avoid direct sunlight (too harsh, creates glare)
- Overcast day = perfect even lighting
- Consistent color temperature

**Artificial Lighting:**
- Use two identical light sources
- Position at 45° angles to map
- Equal distance from map
- Diffuse to avoid glare and shadows
- LED bulbs with consistent color temperature

**Check for:**
- ✅ No glare on map surface
- ✅ No shadows from camera or equipment
- ✅ Even illumination across entire map
- ✅ No hot spots (overly bright areas)

## Part 2: Camera Settings (20 minutes)

### Sony Alpha DSLR Settings

**Shooting Mode:**
- **Manual (M)** - Full control (recommended)
- **Aperture Priority (A)** - Control depth of field (good alternative)
- Avoid: Auto modes (inconsistent results)

**ISO (Sensor Sensitivity):**
- **Set to: 100-200** (lowest available)
- Why: Minimum noise, maximum quality
- Only increase if light is insufficient

**Aperture (f-stop):**
- **Set to: f/8 to f/11**
- Why:
  - Sharp across entire frame
  - Good depth of field
  - Lens sweet spot (sharpest performance)
- Avoid: Wide open (f/1.8-2.8) - too shallow
- Avoid: Very small (f/16+) - diffraction reduces sharpness

**Shutter Speed:**
- Adjust for proper exposure
- Tripod allows slow shutter speeds (1/10s or slower OK)
- Use camera's light meter to guide
- Slightly underexpose rather than overexpose

**Focus:**
- **Manual focus** or **Single AF point**
- Focus on center of map
- Check focus before shooting!
- Use Live View and zoom to verify sharpness

**White Balance:**
- **Custom WB** using color card (see below)
- Alternative: Daylight (5500K) or Cloudy if no color card
- Shoot RAW to adjust later if needed

**File Format:**
- **RAW (.dng for Sony)** - Maximum quality, full editing control
- **RAW + JPEG** - Best of both worlds
- Avoid: JPEG only (unless storage limited)

### Using the Color Card

**What is a Color Card?**
- Reference card with known colors
- Allows accurate color correction
- Ensures consistent color across photos

**How to Use:**

**Step 1: Include in First Shot**
1. Place color card on map
2. Ensure it's well-lit (same light as map)
3. Fill card in frame (but don't cover map content)
4. Take reference shot

**Step 2: Set Custom White Balance**
1. Review reference photo on camera
2. Camera Menu → White Balance → Custom
3. Select reference photo with color card
4. Camera analyzes and sets white balance

**Step 3: Shoot Maps**
1. Remove color card
2. Shoot maps with custom WB
3. Colors will be accurate!

**Step 4: Post-Processing**
1. Import to computer
2. Use color card reference in editing software
3. Apply color correction to all photos from that session

## Part 3: Photography Workflow (15 minutes)

### Pre-Flight Checklist

Before each map:
- ✅ Map clean and flat
- ✅ Camera battery charged
- ✅ Memory card has space
- ✅ Tripod stable
- ✅ Camera level
- ✅ Lighting even
- ✅ No glare visible
- ✅ Settings correct

### Shooting Procedure

**For Each Map:**

1. **Prepare Map**
   - Place flat on surface
   - Straighten edges
   - Use weights if curling
   - Remove any debris

2. **Frame Shot**
   - Fill frame with map
   - Include all edges and borders
   - Capture legend, title block, scale bar
   - Leave small margin around edges

3. **Check Settings**
   - Verify ISO, aperture, shutter speed
   - Check white balance
   - Review focus

4. **Take Multiple Shots**
   - First shot: With color card
   - Remove card
   - Take 2-3 shots of map
   - Bracket exposure if uncertain (one stop darker, one stop lighter)

5. **Review on Camera**
   - Zoom in to check sharpness
   - Check histogram (avoid blown highlights)
   - Verify no glare or shadows
   - Retake if any issues

6. **Document**
   - Note map title/number
   - Note any special conditions
   - Keep maps organized

### Image Quality Assessment

**Check for:**

**Sharpness:**
- Zoom to 100% on camera LCD
- Text should be crisp
- Fine lines clear
- No motion blur

**Exposure:**
- Histogram should be centered
- No pure white areas (blown highlights)
- No pure black areas (blocked shadows)
- Detail visible in both light and dark areas

**Color:**
- Colors look natural
- No color cast (orange, blue tint)
- Consistent with actual map

**Composition:**
- Entire map visible
- Edges not cut off
- Map fills frame efficiently
- No major distortion

**If Any Issues:**
- Retake immediately
- Don't assume "I can fix it later"
- Much easier to reshoot than to fix bad photo

## Part 4: Special Challenges (10 minutes)

### Glossy Maps (Glare Issues)

**Problem:** Shiny surface reflects lights

**Solutions:**
- Use polarizing filter on lens
- Angle lights more obliquely (lower angle)
- Use larger, more diffuse light source
- Photograph on overcast day with window light
- Slightly rotate map to move glare out of frame

### Large Maps

**Problem:** Map larger than camera frame at optimal distance

**Solutions:**
- Move camera higher (if tripod allows)
- Use wider angle lens (if available)
- Shoot in sections and stitch later (advanced)
- Focus on most important section if full map not critical

### Damaged or Fragile Maps

**Problem:** Can't flatten map without damage

**Solutions:**
- Use gentle weights on corners only
- Photograph sections if necessary
- Work quickly to minimize handling
- Consider professional conservation before digitizing
- Document damage in photos

### Low Light Situations

**Problem:** Insufficient light in office

**Solutions:**
- Increase ISO (but keep as low as possible - max 800)
- Open aperture slightly (f/5.6 still acceptable)
- Slower shutter speed OK with tripod
- Add supplemental lighting
- Move to better-lit location if possible

### Color-Faded Maps

**Problem:** Map colors have faded over time

**Solutions:**
- Color card especially important
- Shoot in RAW for maximum editing flexibility
- May need color correction in post-processing
- Document original color (if known)
- Note fading in metadata

## Part 5: File Transfer and Organization (10 minutes)

### Transferring Files

**From Camera to Computer:**

**Method 1: Card Reader (Recommended)**
- Remove SD card from camera
- Insert in card reader
- Copy files to computer
- Faster than USB cable
- Doesn't drain camera battery

**Method 2: USB Cable**
- Connect camera to computer
- Camera appears as drive
- Copy files
- Keep camera powered on

**Best Practice:**
- Don't delete from card until backup confirmed
- Keep originals on card until project complete
- Verify file integrity after transfer

### File Naming Convention

**Bad Names:**
- IMG_0001.jpg
- DSC_1234.dng
- photo.jpg

**Good Names:**
- Quinhagak_ANCSA_14c_1982.dng
- Quinhagak_Infrastructure_1975_01.dng
- LandUse_Map_Sheet2_1990.dng

**Format:**
`[Location]_[MapType]_[Year]_[SheetNumber].extension`

**Why Good Names Matter:**
- Easy to find files later
- Understand what file contains without opening
- Sort and organize easily
- Professional standard

### Folder Organization

**Recommended Structure:**
```
Digitized_Maps_2024/
├── RAW_Files/
│   ├── Quinhagak_ANCSA_14c_1982.dng
│   └── Quinhagak_Infrastructure_1975.dng
├── Processed/
│   ├── Quinhagak_ANCSA_14c_1982.tiff
│   └── Quinhagak_Infrastructure_1975.tiff
├── For_Georeferencing/
│   ├── Quinhagak_ANCSA_14c_1982.jpg
│   └── Quinhagak_Infrastructure_1975.jpg
└── Documentation/
    └── Map_Inventory.xlsx
```

### Backup Strategy

**3-2-1 Rule:**
- **3** copies of every file
- On **2** different media types
- **1** copy off-site

**Example:**
1. Original on computer hard drive
2. Copy on external hard drive
3. Copy on cloud storage (OneDrive, Google Drive, etc.)

**For Quinhagak Project:**
- Working files on computer
- Backup to external drive
- Upload to ArcGIS Online (serves as cloud backup)
- Keep originals on SD card until project complete

## Troubleshooting Common Issues

### Images are Blurry

**Possible Causes:**
- Camera shake (not using tripod or timer)
- Poor focus
- Subject movement (map shifted)
- Shutter speed too slow (if handheld)

**Solutions:**
- Always use tripod
- Use 2-second timer or remote
- Lock down map
- Check focus carefully

### Colors Look Wrong

**Possible Causes:**
- Incorrect white balance
- Mixed lighting (window + fluorescent)
- Color cast from colored walls/surface

**Solutions:**
- Use color card and custom WB
- Use single light source type
- Photograph on neutral surface

### Uneven Brightness

**Possible Causes:**
- Single light source
- Light too close to one side
- Vignetting (lens characteristic)

**Solutions:**
- Use two lights, equal distance
- Position lights farther away
- Use smaller aperture (f/11)

### Glare/Reflections

**Possible Causes:**
- Glossy map surface
- Direct lighting
- Wrong light angle

**Solutions:**
- Use polarizing filter
- Diffuse light source
- Adjust light position
- Photograph on overcast day

## Key Takeaways

1. **Tripod is essential** - No exceptions for quality work
2. **Low ISO, medium aperture (f/8-f/11)** - Recipe for sharp images
3. **Color card ensures accurate colors** - Professional standard
4. **Even lighting prevents problems** - Worth taking time to set up right
5. **Take multiple shots** - Insurance against mistakes
6. **Review on camera** - Reshoot immediately if problems
7. **Good file names and organization** - Future you will thank you
8. **Backup everything** - Don't lose irreplaceable work
